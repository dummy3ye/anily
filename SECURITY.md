# Security Policy

## Supported versions

Only the latest release on the default branch is currently supported.

## Reporting a vulnerability

Do not open a public issue for a security vulnerability. Use
[GitHub private vulnerability reporting](https://github.com/dummy3ye/anily/security/advisories/new)
if it is enabled, or contact the repository owner privately through GitHub.

Include the affected version or commit, operating system, reproduction steps,
impact, and any suggested mitigation. Please do not include secrets in a
report.

We will acknowledge reports as soon as practical, investigate privately, and
coordinate disclosure after a fix is available.
